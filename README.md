# Time Recorder
Simple time recorder app.

**Main Display**

![main_display](./main_screen.png)

## Build

**Development Build**
```
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m pip install -e .

# run
time_recorder
```


## Setup

* `pyside6-designer` - edit the .ui file.
* `pyside6-uic` - window.ui -o ui_window.py
